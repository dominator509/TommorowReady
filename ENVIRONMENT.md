# Environment

Node.js 24.x, pnpm 10.x through Corepack, Docker 27+, PostgreSQL client 17+, Git 2.45+, curl, jq, OpenSSL, and POSIX sh are required. Local uses Docker Compose services. Test uses isolated databases and buckets. Staging mirrors production providers with sandbox accounts. Production uses secret management and manual approval. Every environment variable is validated at startup; unknown production variables fail review, missing required variables fail startup, and secrets are redacted.

## Local bootstrap

Run `sh scripts/bootstrap-local-env.sh`, then `docker compose up -d --wait`. The generated `.env` is ignored, mode-restricted where supported, and contains distinct local-only PostgreSQL owner/application, S3, session-signing, authentication-lookup, recovery-token, field-encryption, and backup-encryption credentials. `DATABASE_MIGRATION_URL` and `POSTGRES_PASSWORD` are migration/infrastructure-only; the application uses the non-superuser, non-bypass-RLS `DATABASE_URL`. `PASSKEY_RP_ID` and `PASSKEY_ORIGIN` must exactly match the browser relying-party domain and origin; local uses the WebAuthn-valid RP `localhost` and `http://localhost:3000`, while production requires its approved HTTPS origin. `API_BASE_URL` points the web BFF at the local API on port `4000`; browser code never receives the API bearer token. Mailpit captures real SMTP recovery traffic locally. Optional external providers remain unset and fail closed.

Production release configuration is separate from local bootstrap values. `PRODUCTION_BASE_URL`, `APP_BASE_URL`, `PASSKEY_ORIGIN`, storage and SMTP endpoints must be approved non-local HTTPS/TLS endpoints; both `DATABASE_URL` and `DATABASE_MIGRATION_URL` require an explicit TLS `sslmode`, and Redis requires `rediss:`. `PRODUCTION_EVIDENCE_FILE`/`PRODUCTION_EVIDENCE_SHA256`, `RELEASE_COMMIT`, `PRODUCTION_MANIFEST`/`PRODUCTION_MANIFEST_SHA256`, cluster context/namespace, and explicit deployment authorization bind a reviewed release. Rollback uses its separately approved `ROLLBACK_MANIFEST_SHA256`. These values and all production credentials belong in the approved secret/evidence systems, never in Git.

Observed host baseline on 2026-08-06: Node 24.14.1, Docker 29.5.3, Compose 5.1.4, Git 2.55.0, PostgreSQL client 18.4. Corepack initially exposed pnpm 9.15.0; the repository must pin and activate pnpm 10.x in EP-001. Host `redis-cli` is absent, so the read-only Redis probe uses the real Valkey container CLI.
